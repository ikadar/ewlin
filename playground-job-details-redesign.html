Variantes header — v2

Baseline et choix de header v1 figés. Focus sur 3 axes que tu m'as demandés : identité+client+désignation, BAT+deps groupés, précédence élément en ligne à droite.

Hiérarchie identité (ref · client · désignation)

Ref en tête : ref mono large + client + description muette. Désignation : la description devient le titre, ref·client en pied. Compact : ref·client fusionnés ligne 1, description medium ligne 2.

Layout BAT + dépendances

Séparés : Départ+BAT dans l'encadré deadlines, deps inline hors boîte (v1). BAT+deps : Départ seul en tête, BAT et dépendances ensemble dans un même encadré aligné à gauche.

Précédence élément

"Après Couverture Intérieur" apparaît soit sous le titre de l'élément, soit sur la même ligne calé à droite.
