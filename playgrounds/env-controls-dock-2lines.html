Comparatif côte-à-côte. Chaque colonne montre l'état préprod en haut et prod en bas. Largeur fixée à 280 px partout pour que le verdict porte sur la hauteur, pas l'occupation.

B · 2 lignes — toggle EST le header
Pour éditer, bascule en préprod

Le toggle prend toute la largeur. La couleur du header dit l'env actif. Sous-titre perdu mais l'info "où je suis" est plus directe (le côté allumé du toggle).

C · 2 lignes — header + chevron switch
Pour éditer, bascule en préprod

Le header complet est cliquable pour basculer. L'env actif est nommé clairement, la flèche dit "il existe une autre face". Plus calme que B, mais l'env inactif n'est pas montré.

Mon avis : B est le meilleur compromis si tu veux du 2-lignes. Le toggle plein-largeur sert de header coloré ET de sélecteur ; pas de risque de confusion comme C ; les 24 px gagnés sont notables sur un FAB.

L'argument pour A reste le sous-titre — utile pour rappeler "Engagé en atelier" quand on est en prod (instinctif pour garder le bon réflexe de prudence).

Le scénario shell continue d'utiliser la version 3 lignes (header avec nom de la branche + sous-titre + actions) car la branche A NE SE TOGGLE PAS — il n'y a rien à mettre dans un toggle.
