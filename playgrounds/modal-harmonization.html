Récap — ce que la migration change

Conteneur
  • • rounded-lg / rounded-xl → rounded-[7px]
  • • bg-flux-elevated → bg-zinc-950
  • • border-flux-border → border-zinc-800
  • • shadow-xl → shadow-2xl
Header / Footer
  • • Header en bandeau bg-zinc-900 + icône 28px
  • • Titre text-[15px] leading-[23px] medium
  • • Padding header 13px / 10px
  • • Footer 2 bandeaux : hint + actions, gap 10px
Boutons / champs
  • • Boutons px-[13px] py-[6px] text-sm
  • • Radius bouton 3px
  • • Annuler : bg-zinc-800 (plus visible)
  • • Inputs px-[10px] py-[6px] bg-zinc-900 border-zinc-800 rounded-[3px]
Avant d'implémenter. Si les choix te conviennent, je propose : (1) ajouter un composant Modal + ConfirmDialog partagés sous apps/web/src/components/Modal/, (2) refactoriser les 4 modales nommées en se basant dessus, (3) remplacer les window.confirm par ConfirmDialog. Le diff sera majoritairement de la suppression de classes flux-* + import du nouveau Modal — pas de logique métier touchée.
