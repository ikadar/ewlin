Tuile — icône saisie (3 états) + menu contextuel nettoyé

Deux changements visuels sur la tuile, illustrés ensemble : (1) une icône saisie remplace l'ancienne case de complétion ; elle prend trois états selon le contexte (inactive, hourly, tile-end). (2) Le clic droit ouvre un menu contextuel simplifié à 3 items pour le contexte prod, conformément aux décisions du doc design.

Joue avec le simulateur à gauche pour voir l'icône changer d'état. Clic-droit sur la tuile F2 pour voir le nouveau menu. Click sur l'icône → toast (en vrai, ça ouvrirait la modale d'avancement v5).

Le 4e item ouvre un sub-dialog jour/heure puis crée un pin paramétré. Mécanique : si le créneau est dispo → pin direct ; sinon → slide-to-nearest + warning modale (comportement Pin existant verbatim, on n'invente rien). Permet aussi de déplacer un pin en place sans avoir à unpin → re-pin.

Note : le menu admin/préprod peut conserver les items algo (Rappeler, Diviser, Fusionner). Le composant TileContextMenu les expose déjà comme props optionnelles ; chaque vue ne passe que ce qui lui est pertinent.

Règles de l'icône saisie
  • Inactif par défaut — petit rond gris, ~55% d'opacité, hover à 100%. Cliquable même sans trigger pour saisie proactive de l'opérateur.
  • Hourly — apparaît à chaque heure pleine pendant qu'une tuile est in-progress, sauf si une saisie a eu lieu dans les 30 dernières min (debounce). Double signal subtil : icône bleu plein + pulse en opacité pure sur la tuile entière (cycle 1,6 s, pas de changement de couleur). Le signal est présent dans le champ visuel sans mobiliser un code couleur.
  • Tile-end — apparaît quand now ≥ scheduledEnd. Double signal synchronisé en couleur : la tuile entière pulse vers et depuis l'orange (cycle 1,6 s), l'icône amber pulse au même rythme. L'orange est distinct des codes métier (default, completed, late, conflict) — il ne signifie qu'« un moment de saisie ». Si l'opérateur n'agit pas, l'auto-completion silencieuse prend le relais.
  • Click → modale — quel que soit l'état. La modale est la seule porte d'entrée à la saisie.
  • Position de l'icône — coin haut-gauche du label, au même endroit que l'ancienne CompletionToggleIcon. Suit l'icône Pin.
À ton retour
  1. L'icône inactive à 55% d'opacité — assez discrète, ou trop discrète (risque d'être ignorée pour la saisie proactive) ?
  2. Le pulse amber tile-end à 1,6 s — bon rythme, ou trop rapide / trop lent ?
  3. L'ordre dans le menu contextuel (Détails / Saisir / Épingler) — bon, ou tu préfères Saisir en premier (puisque c'est l'action principale) ?
  4. Le séparateur dans le menu — utile (pour grouper Détails seul vs Actions), ou superflu sur 3 items ?
  5. Faut-il fermer l'icône immédiatement après une saisie réussie (revenir en inactif), ou attendre quelques secondes pour confirmation visuelle ?
