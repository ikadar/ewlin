Focus View — Mono-colonne Station / Opérateur

Page dédiée avec URL propre, accessible depuis les en-têtes de colonnes. Optimisée mobile, utilisable desktop.

URL courante : /focus/operator/adrien

Déclencheur — survol en-tête colonne (multi)

Sur la vue multi-colonnes, l'icône apparaît au survol. Sur mobile, elle est toujours visible.

Choix par défaut (modifiables)

  • • URL : /focus/operator/:id et /focus/station/:id
  • • Dropdown : un seul sélecteur avec sections Stations / Opérateurs + recherche (JCF-style)
  • • Bouton NOW : LocateFixed (cible), toujours visible bottom-right
  • • Tuiles : Tile sur station, TileSegment sur opérateur (cohérent avec vues parent)
  • • Survol en-tête : icône ExternalLink à droite du nom (visible au hover desktop, toujours en mobile)
  • • Mobile : colonne pleine largeur, frise d'heures sticky gauche (préserve le geste habituel)
  • • Back : chevron explicite, en plus du bouton natif
  • • Interactions tuiles : clic → modal job (read-only pour cette itération)

À arbitrer

  • • Conserver les interactions tuiles (drag, pin, toggle complete) ou lecture seule ?
  • • Encoder la date dans l'URL (?d=2026-04-16) pour partage ?
  • • Zoom sur mobile : boutons +/-, pinch-to-zoom, ou figé ?
  • • Masquer le bouton NOW quand la ligne est déjà visible ?
  • • Cible du bouton retour : vue multi-colonnes dont on vient, ou accueil fixe ?
