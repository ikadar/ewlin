Similarity Badge

Matrice interactive 7 axes. Tourne les potards, le rendu se met à jour en live. Clic "Exporter" pour sérialiser la combinaison en JSON.
1. Position
2. Info density
3. Sémantique couleur
4. Taille
5. Visibilité
Seuil: 30%
6. Normalisation
7. Interaction
8. Forme (shape)
Quand shape ≠ pill, les axes 1 (position) et 4 (taille) sont ignorés ; la taille contrôle à la place l'épaisseur/unit-width. 

  


  
  

    
Presses Offset — toute l'échelle 0 → 7

    
8 paires, une par valeur possible du score. maxPoints = 7. Les paires factices sont colorées pareil (même client) pour rester discrètes ; le badge seul doit porter le signal.

    


    
Pelliculeuses — le cas du 0.5 fractionnaire

    
maxPoints = 3. paper_type seul = 0.5 (cas unique parmi toutes les catégories). Teste le rendu d'un nombre non-entier avec chaque normalisation.

    


    
Massicots — maxPoints minimal

    
maxPoints = 1. Sur fraction/pourcentage ça donne "1/1" et "100 %" au moindre match — attention au signal comparé à l'Offset.

    


    
Finition — cas standard 2 critères

    
maxPoints = 3. paper_weight seul = 0 (sans format il n'apporte rien), pair total = 3.

    


    
Cas bords

    
Catégorie sans règles, première tuile (pas de prédécesseur), neutralisation complète, neutralisation partielle.

    


    
Stress tests visuels

    
Tuile très courte, tuiles strictement collées (gap = 0), label long qui croise le badge, densité haute.

    


    

      Notes de lecture.

      • Les couleurs "Per famille" utilisent : inking indigo, paper ambre, format ciel.

      • Le gradient continu va de neutre (0) à emerald (max).

      • Le gradient par paliers (stepped) : rouge (< 33 %), ambre (33–66 %), emerald (> 66 %) — lecture "feu tricolore".

      • La normalisation s'applique uniquement au texte du badge ; la couleur s'appuie toujours sur points/maxPoints quand elle est continue.

      • Shapes bar-* : largeur = score × unit_width (4 px par point en taille "small"). Aucune "track" vide — seule la portion "atteinte" est rendue. Ça rend deux scores égaux de catégories différentes visuellement identiques.

      • bar-stacked colorise automatiquement chaque segment par sa famille de règle quand couleur = per-criterion.

      • Le bouton Exporter produit un JSON réutilisable par le composant React (B5 du plan).
