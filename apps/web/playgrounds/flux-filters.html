Décisions UX retenues

  • Multi-selects compacts : libellé seul si vide, libellé + badge bleu de comptage si valeurs sélectionnées (ex. Client (3)). Bordure bleue quand actif.
  • Dates : deux <input type="date"> natifs côte-à-côte, un X pour effacer ; pas de date picker custom (cohérent avec DateTimePicker).
  • Statut = 5 valeurs synthétiques (À traiter / En préparation / Prêt à imprimer / Parti / Facturé) — pas les 11 statuts de prérequis bruts (qui doublonneraient avec les onglets).
  • Lien Réinitialiser à droite du bandeau, désactivé si aucun filtre actif.
  • Logique : AND inter-filtres, OR intra-filtre multi-select. La barre de recherche reste indépendante.
  • Filtres options dynamiques : Client / Transporteur / Numéro dossier listent uniquement les valeurs présentes dans les jobs visibles (pas les 1000 clients du back).
