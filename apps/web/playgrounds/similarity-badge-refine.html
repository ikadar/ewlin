      Notes de lecture.

      • Mode per-point : largeur totale = maxPoints × unit. Offset (max=7) à unit=4 → track de 28 px. Massicots (max=1) à unit=4 → track de 4 px. Les catégories plus "riches" ont une jauge plus large.

      • Mode fixed : largeur totale constante pour toutes les catégories ; le remplissage est un pourcentage du total.

      • Les seuils stepped s'appliquent au fill. Un score 4/7 (ratio 0.57) en seuils 33-66 tombe dans "mid" (ambre) ; en seuils abs 2/4 → "high" (emerald) puisque le score ≥ 4.

      • track=visible-tinted teinte la track avec la couleur de palette à faible opacité — ambiance cohérente.

      • Le bouton Prompt Claude produit un prompt prêt-à-coller avec la config complète et les instructions pour B5.
