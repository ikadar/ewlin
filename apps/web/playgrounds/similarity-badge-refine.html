      Lecture.

      • Seuils stepped : par ratio (score / maxPoints) ou absolu (palier en points bruts).

      • La palette Classique suit la convention feu tricolore (red-400 / amber-400 / emerald-400).

      • Palette Sobre reste en tons verts (zinc-500 → emerald-400) pour une lecture moins alarmiste.

      • Palette Chaud-froid passe du bleu (rare) au vert (fréquent) — évite le rouge qui porte une connotation "erreur".

      • Palette Mono joue uniquement sur l'opacité.

      • Le bouton Prompt Claude produit un prompt prêt-à-coller reprenant exactement la config affichée.
