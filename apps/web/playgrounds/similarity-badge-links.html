Pour chaque catégorie, un indicateur par niveau de score atteignable. Les scores possibles sont listés devant.

    


    

      Récap N maillons par catégorie (hors score 0)

      • Offset → 5 : scores possibles 2, 3, 4, 6, 7

      • Pelliculeuses → 3 : 0.5, 1, 3

      • Finition (Plieuses / Encarteuses-Piqueuses / Assembleuses / Assembleuses-Piqueuses / Conditionnement) → 2 : 1, 3

      • Massicots → 1 : 1

      • Typographie → 0 (rien à afficher)


      Remplissage ordinal : le nème indicateur est allumé si score ≥ niveau[n]. Ex. Offset score 4 → 3 maillons pleins (niveaux 2, 3, 4 tous ≤ 4), 2 maillons vides (niveaux 6 et 7 non atteints).


      Option "mono par intensité" : le maillon rempli a une couleur d'autant plus foncée qu'il est loin dans la séquence. Utile pour que l'œil distingue un maillon à gauche (palier bas) d'un maillon à droite (palier haut) sans lire la position.
